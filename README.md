# 守破離 (Shuhari) - 武道・芸事の修練と内省を深める稽古ノート

![守破離 アイコン](images/app_icon.png)

> **「稽古を刻み、守破離の境地へ。」**  
> 居合道・合気道・剣道・茶道・華道など、道を志すあらゆる修練者のための稽古記録・内省支援アプリケーション。

---

## ✦ 守破離（Shuhari）とは？

「守破離」は、日本の伝統的な武道や芸事において、修練者が成長していくプロセスを表す重要な哲学です。

| 段階 | 意味 | アプリでの活用 |
| :---: | :--- | :--- |
| **守 (Shu)** | 師の型を忠実に守り、基本を身体に染み込ませる段階 | 日々の稽古回数、日時、基本動作の振り返りを着実に記録。 |
| **破 (Ha)** | 基本を土台に他を学び、殻を破って模索する段階 | 試行錯誤の気付きや疑問点をAIとともに整理し、新たな視点を獲得。 |
| **離 (Ri)** | すべての型から自由になり、独自の自然な境地を開く段階 | 月間・年間の修練の軌跡を俯瞰し、生涯の探求に伴走。 |

## ✦ 主要機能のご紹介

### 1. 日本の祝日 & 行数切り替え対応の月間カレンダー
- 国民の祝日（振替休日・ハッピーマンデー）の自動判定および和風バッジ表示。
- スケジュールの密度に応じて、カレンダーセルの高さを「2行・3行・4行」に自由に変更可能。
- 日付をタップして日別の稽古カードを即座に確認。

### 2. 音声入力 & 当日・過去日の直接実績入力
- マイクボタンをタップするだけで、道場の着替え中や帰路でも手軽に音声メモを入力可能。
- 日付が当日または過去日の場合、★1〜5の星評価と実績メモ入力欄が自動展開。予定作成から振り返りまでワンストップで完了します。
- Google Places連携による道場・稽古場所の自動検索＆外部地図アプリ連携。

### 3. テキスト流し込みによるAI予定一括作成
- LINEやメールに届いた「8月の稽古予定です…」などの連絡文面をそのまま貼り付けるだけ。
- AIが日程・時間・場所・ジャンルを自動抽出してカレンダーへ一括登録。
- 時間の指定がない場合は自動的に「終日 / 時間未定」として整理。既に登録済みの重複予定も自動で検知・除外します。

### 4. 重点課題（タスク）＆ 備忘メモ
- 師匠から指摘された改善点や克服すべきテーマを「守・破・離」ステージ別に整理・管理。
- 克服した課題はいつでも復元可能。AIが過去の課題解決を自動でサジェストします。

### 5. 和の美意識を取り入れた3つのテーマ
- 「禅（Zen）」「漆（Urushi）」「モダン（Modern）」の3つのデザインテーマをワンタップで切り替え。
- 夜間の稽古後にも目に優しいダークモードを完備。

### 6. 武道・芸事のデジタル名刺プロフィール
- 段位・所属道場・流派・入門年などを記載したデジタル名刺を作成。稽古仲間との交流やSNSシェアに役立ちます。

## ✦ 安心のプライバシー設計（完全スタンドアロン）

- **アカウント登録・ログイン不要**: アプリを起動した瞬間からすべての機能をご利用いただけます。
- **完全ローカル保存**: 大切な稽古記録や反省メモは、すべてお使いの端末内（IndexedDB / ローカルストレージ）にのみ安全に保存されます。
- **オフライン動作対応**: 電波の届かない道場や地下の稽古場でも軽快に動作します。
- **データのエクスポート/復元**: CSVおよびJSON形式でのバックアップ・復元に対応。
